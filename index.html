01 Hello, world.

      

        
I'm an embedded engineer who likes the layer where software meets silicon — registers, interrupts, timing diagrams, and the moment a scope trace finally matches the datasheet.

        

          
I design and ship firmware for industrial trackers and electronic locks at KritiLabs Technologies, with a focus on reliability: non-blocking drivers, circular DMA buffers, state machines, and over-the-air updates so devices never need a technician with a programmer.

          
Before that I built an edge-AI computer-vision system at Innospace Automation, and at college I built assistive-tech projects that earned an IEEE EPICS grant, an IEEE Xplore publication and a second IEEE paper submission. I'm looking for a firmware or product-development role where I can own a device from the PCB to the cloud.

KritiLabs · 2025–NowPRODUCTION

          
Vehicle Tracking System + Secure OTA

          
STM32-based industrial tracker that streams data over GSM/GPRS to the cloud via MQTT — and updates itself in the field.

          

            
    
              
  • Non-blocking UART driver using circular DMA buffers to talk to the GSM/GPRS modem.
    • 
              
  • Zero packet loss during continuous MQTT data transmission.
    • 
              
  • Secure OTA firmware updates — no more manual on-site flashing.
    • 
              
  • I2C / SPI / UART bring-up for sensors and peripherals on custom PCB hardware.
    • 
              
  • Timing issues, interrupts and bus conflicts debugged with a scope and logic analyzer.
